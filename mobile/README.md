# Bonk Docs Mobile

React Native host skeleton for Bonk Docs.

Kept in place:

- Expo React Native app shell
- React Navigation drawer setup
- Pear Runtime / Bare worklet bootstrap
- Pear storage wiring for the shared worker

Removed for now:

- old document list/editor flows
- generated mobile editor bundle
- mobile-specific RPC wrappers

## Commands

```sh
npm install
npm run bundle:bare
npm run ios
```
